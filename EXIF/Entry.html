    class EXIF::Entry

    • EXIF::Entry
    • Reference
    • Object

    Overview

    A single EXIF tag together with its value.

    entry = data[:exposure_time]
entry.name   # => "ExposureTime"
entry.title  # => "Exposure Time"
entry.format # => EXIF::Format::Rational
entry.value  # => EXIF::URational(1/250)
entry.to_s   # => "1/250 sec."

    Defined in:

    exif/entry.cr

    def to_s(io : IO) : Nil #

    Returns the human-readable (localized) value of the entry, as formatted by libexif.

    NOTE libexif can't format entries removed from their IFD (it needs their byte order), Format::Float and Format::Double values, nor most user comments (i.e. Unicode ones, or ones without a character code), so these are formatted from their decoded #value instead (user comments without any trailing padding).

    def value=(value) #

    Encodes and stores the given value.

    Integers, floats and rationals may be given either as a scalar or an Array, String is accepted by Format::Ascii, Format::Undefined and Format::Byte entries (encoded as defined for Tag::UserComment and the Tag::XPTitle-like tags), Bytes by Format::Undefined, Format::Byte and Format::SByte ones.

    Raises ValueError if the value can't be stored in the entry format, i.e. text containing NUL characters (which would end it) in other than plain Format::Undefined and Format::Byte entries, and ArgumentError for tags generated by libexif (see Tag#managed?), as well as for Tag::MakerNote entries outside of the IFD::EXIF (see Data#maker_note?).
