    class EXIF::Content

    • EXIF::Content
    • Reference
    • Object

    Overview

    Holds all entries of a single IFD.

    exif = data.ifd(:exif)
exif.size                  # => 30
exif[:exposure_time].value # => EXIF::URational(1/250)
exif.map(&.name)           # => ["ExposureTime", "FNumber", ...]
